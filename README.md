# 🌫️ Air Quality Dashboard — India

Real-time air quality monitoring system for major Indian cities using Python and OpenWeatherMap API.

## 🚀 Features
- Live AQI (Air Quality Index) data for 10 Indian cities
- Pollutants tracked: PM2.5, PM10, CO, NO2, O3
- Colorful bar charts for each city
- AQI level labels: Good, Fair, Moderate, Poor, Very Poor

## 🏙️ Cities Covered
Mumbai, Delhi, Ahmedabad, Surat, Pune, Bangalore, Chennai, Kolkata, Hyderabad, Jaipur

## 🛠️ Tech Stack
- Python 3
- Requests (API calls)
- Matplotlib (graphs)
- Pandas
- OpenWeatherMap API

## ⚙️ Setup
1. Clone the repo
   git clone https://github.com/dhyanpatel1327-pixel/air-quality-dashboard.git

2. Install dependencies
   pip install requests matplotlib pandas

3. Add your API key
   Create config.py and add:
   API_KEY = "your_openweathermap_api_key"

4. Run
   python3 app.py

## 📊 Sample Output
- City name and AQI level
- Pollutant concentrations in μg/m³
- Bar chart saved as PNG
